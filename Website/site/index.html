Mystery Quest

A fan-made TTRPG ruleset for Mystery Dungeon and other Pokémon-only adventures.

Everything runs in your browser — no account, no server. Your characters are stored locally; use the JSON data menu in the top bar to download them as a JSON file or upload one to continue later.
